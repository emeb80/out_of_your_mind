# Out of Your Mind

## Om projektet

Out of Your Mind är ett fiktivt escape room-företag inspirerat av ett gammalt mentalsjukhus. Webbplatsens syfte är att presentera verksamheten, skapa intresse för upplevelsen och ge besökaren den information som behövs inför ett besök.

## Webbplatsens innehåll

Webbplatsen består av fem HTML-sidor:

- **Startsida:** Introducerar konceptet.
- **Hem:** Presenterar verksamheten och ger introduktion till upplevelsen.
- **Våra rum:** Beskriver de olika rummen och deras berättelser.
- **Kontakt:** Innehåller formulär för kontakt samt sektion med FAQ.
- **Bokning:** Innehåller formulär för bokningsförfrågan och villkor.

## Funktioner

- Responsiv design för mobil och dator.
- Navigeringsmeny med hamburgermeny i mobilläge.
- Validering av bokningsformulär.
- Validering av kontaktformulär.
- Funktion för att visa och dölja bokningsvillkor.

## Tekniker

Projektet har utvecklats med:

- HTML för webbplatsens struktur.
- CSS för design, layout och responsiv anpassning.
- JavaScript för interaktiva funktioner och formulärvalidering.

Figma har använts för att ta fram wireframes och mockups för mobil och dator.

Git och GitHub har använts för versionshantering.

## Begränsningar

Bokningsformuläret kontrollerar att obligatoriska uppgifter är ifyllda, men skickar ingen faktisk bokning. Kontaktformuläret validerar uppgifterna men skickar inget meddelande.

FAQ-funktionen för att visa och dölja svar är inte färdigställd. Ett planerat bildspel på sidan Våra rum har också utgått på grund av tidsbrist.
